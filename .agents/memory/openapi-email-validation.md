---
name: OpenAPI email validation
description: Compatibility rule for email fields generated by the current Orval and Zod versions.
---

For OpenAPI email inputs, use a string `pattern` rather than `format: email` with the current generator setup.

**Why:** Orval emits `zod.email()` for `format: email`, while the generated Zod package currently resolves to an API that does not expose that function, causing library typechecking to fail after code generation.

**How to apply:** Express email validation with an OpenAPI regex pattern, regenerate clients and Zod schemas, and rerun the library typecheck. Revisit this rule after Orval and Zod are upgraded together.
