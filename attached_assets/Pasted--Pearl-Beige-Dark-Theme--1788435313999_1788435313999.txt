غيّر لوحة تحكم الأدمن بالكامل من الوضع الفاتح (Pearl Beige) الحالي إلى وضع داكن كامل (Dark Theme)، باستخدام ألوان الهوية الرسمية الداكنة لمسك اللولو فقط - لا تستخدم ألوان عشوائية خارج دليل الهوية.

## نظام الألوان الجديد (الوضع الداكن)

- خلفية القائمة الجانبية والمحتوى الرئيسي: Near Black (#313031) أو أغمق قليلاً (مثل #1A1A1A) للتباين الأفضل
- النص الأساسي: أبيض/كريمي فاتح (#E9E6DF - نفس Pearl Beige لكن كلون نص هنا بدل خلفية)
- العنصر النشط بالقائمة الجانبية: Peach Gold (#FDC87F) كخط تحديد جانبي (right border) أو خلفية خفيفة شبه شفافة، مع نص أبيض ساطع
- البطاقات (Cards): خلفية أغمق قليلاً من الخلفية العامة (مثل #232323) مع حدود رفيعة بلون رمادي داكن متوسط
- الأزرار الأساسية: خلفية Peach Gold (#FDC87F) أو Terracotta (#C47B47) مع نص داكن (Near Black) للتباين
- حالات النجاح/الاتصال (مثل "مفتوح"، "متصل"): أخضر هادئ ومتوافق مع الوضع الداكن (مثل #4ADE80 بشفافية خفيفة كخلفية)
- حالات الخطأ: أحمر/عنابي متوافق (مثل Deep Maroon #731323 بنسخة أفتح للوضع الداكن)
- فقاعات الدردشة بقسم الواتساب (رسائل الوكيل/الأدمن): خلفية خضراء داكنة متناسقة، رسائل العميل: رمادي داكن محايد

## واجهة قسم "الواتساب → المحادثات" (صندوق دردشة حقيقي، Inbox UI)

هذا قسم UI جديد يحتاج تصميمه (بدون ربط فعلي بـ WhatsApp Business API حاليًا - هذا مؤجل لمرحلة تكامل خارجي لاحقة، اجعله UI shell بس الآن مع بيانات تجريبية Mock):

- عمود يمين: قائمة محادثات (اسم العميل أو رقم الجوال، آخر رسالة، الوقت، مؤشر حالة القراءة)، مع فلاتر أعلاه (الكل/مفتوح/غير مقروء/مؤرشف) وخانة بحث
- منتصف: نافذة المحادثة النشطة (فقاعات رسائل العميل يسار، فقاعات ردود الوكيل يمين بلون مختلف)، حقل كتابة رسالة بالأسفل مع زر إرسال وزر إرفاق ملف
- يسار: معلومات جهة الاتصال (رقم الجوال، القناة "WhatsApp"، الحالة "مفتوح/مغلق"، تاريخ آخر الطلبات)

## إصلاح إضافي: شريط التمرير (Scrollbar)

لاحظنا شريط تمرير بمظهر قديم/كلاسيكي (رمادي غامق بسهم علوي وسفلي، شبيه بمتصفحات Windows القديمة) يظهر حاليًا بدل شريط تمرير حديث ورفيع. أصلح تصميم الـ scrollbar عبر CSS ليكون:
- رفيع (thin)
- بدون أسهم علوية/سفلية
- بلون متناسق مع الوضع الداكن الجديد (رمادي متوسط شفاف للـ thumb، شفاف تمامًا للـ track)
- طبّقه على كل عناصر التمرير بلوحة التحكم (القائمة الجانبية، الجداول، أي عنصر overflow-y)

## ملاحظة تنفيذية مهمة

هذا تعديل بصري وهيكلي بالكامل (Dark theme + تخطيط الواتساب + إصلاح scrollbar) - لا تحتاج ربط فعلي بأي API خارجي لقسم الواتساب الآن (البيانات تجريبية Mock فقط للعرض). لا تكسر أي وظيفة خلفية شغالة حاليًا بالأقسام الأخرى (الطلبات، المنتجات، المحاسبة، بوابة المالك، شؤون الموظفين، إلخ) - هذا تعديل CSS/Layout فقط، مع إضافات بسيطة بالروابط فقط للأقسام الجديدة.

طبّق التغيير على كل صفحات الأدمن الموجودة حاليًا بدون استثناء، اعطني ملخصًا بالملفات المعدّلة، وتأكد أن pnpm run typecheck ناجح.
