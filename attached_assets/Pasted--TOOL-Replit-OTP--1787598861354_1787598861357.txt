## [3] PAGES & ROUTES

### الواجهة العامة
```
/                       → Home (Hero بفيديو + تبويبات الفئات + قسم "العقل المبدع خلف العطور" + قسم من نحن + منتجات مميزة)
/products               → كل المنتجات + فلترة (الفئة: عطور/عطور الشعر، السعر، الأكثر مبيعاً، التقييم)
/products/[slug]        → تفاصيل منتج (معرض صور + السعر + الكمية + إضافة للسلة + منتجات ذات صلة)
/categories/[slug]      → صفحة فئة (عطور / عطور الشعر)
/cart                   → السلة
/checkout               → إتمام الطلب (العنوان + الشحن + الدفع)
/about                  → من نحن (قصة العلامة التجارية — نص الدليل: "Founded in 2011...")
/contact                → تواصل + واتساب + نموذج
```

### حساب العميل (محمي — تسجيل إجباري عبر OTP)
```
/auth/register          → تسجيل برقم الجوال
/auth/verify-otp        → إدخال كود OTP المرسل عبر SMS
/account                → ملخص الحساب
/account/orders         → طلباتي وتتبع الشحن
/account/addresses      → عناويني
/account/profile        → الملف الشخصي
```

### الداشبورد الإدارية (محمية — `/admin`)
```
/admin                  → Overview (مبيعات اليوم، طلبات جديدة، منتجات منخفضة المخزون)
/admin/products         → إدارة المنتجات (إضافة/تعديل/حذف، صور، أسعار، مخزون)
/admin/categories       → إدارة الفئات
/admin/orders           → إدارة الطلبات (حالة: جديد/قيد التجهيز/تم الشحن/تم التسليم/ملغي)
/admin/customers        → قاعدة بيانات العملاء
/admin/coupons          → إنشاء وإدارة أكواد الخصم (نسبة/مبلغ ثابت، تاريخ انتهاء، حد استخدام)
/admin/shipping         → إعدادات تكامل الشحن (Storage Station) ومتابعة الشحنات
/admin/content          → CMS: تعديل نصوص وفيديو/صور الصفحة الرئيسية وقسم "من نحن" بدون كود
/admin/reports          → تقارير المبيعات (يومي/أسبوعي/شهري، الأكثر مبيعاً)
/admin/settings         → إعدادات عامة (رقم واتساب، مزوّد SMS، مزوّد الشحن، بيانات ضريبية)

```

## [11] AUTHENTICATION & SECURITY
- **تسجيل إجباري** برقم الجوال قبل إتمام أي عملية شراء (Guest Checkout غير متاح)
- **OTP:** كود 4-6 أرقام عبر SMS، صلاحية 5 دقائق، حد 3 محاولات إعادة إرسال بالساعة
- **JWT:** Access (15 دقيقة) + Refresh (30 يوم — بما إنه متجر يُفضَّل بقاء تسجيل الدخول لفترة أطول للعملاء)
- **Rate Limiting** على إرسال OTP ومحاولات تسجيل الدخول
- **PCI Compliance:** لا تُخزَّن بيانات بطاقات الدفع مطلقاً — تُدار بالكامل عبر Moyasar/Tabby/Tamara SDKs
- **CSRF Protection** على كل عمليات الداشبورد
