أضف 3 وحدات جديدة كاملة بلوحة تحكم مسك اللولو (ضمن خطة اللوحة الشاملة)، بنفس نمط الحماية بالصلاحيات الموجود حاليًا (permit("module", "action")) ونفس أسلوب الهوية البصرية المطبّق حاليًا (Tajawal، ألوان Pearl Beige/Charcoal Grey/Terracotta/Peach Gold).

## 1. شؤون الموظفين (HR)

جداول جديدة:
- employees: id, name, national_id, phone, email, position, department, salary, hire_date, is_active, admin_user_id (FK اختياري لربط الموظف بحساب أدمن لو عنده وصول للوحة)
- attendance_records: id, employee_id (FK), date, check_in_time, check_out_time, status (enum: present, absent, late, on_leave), notes
- leave_requests: id, employee_id (FK), leave_type (enum: annual, sick, emergency, unpaid), start_date, end_date, status (enum: pending, approved, rejected), reason, approved_by (FK إلى admin_users.id)
- payroll_records: id, employee_id (FK), month, year, base_salary, deductions, bonuses, net_salary, payment_date, payment_status (enum: pending, paid)

Endpoints (كل واحد محمي بصلاحية "hr":"view"/"edit"/"delete" - أضف هذي الصلاحية الجديدة لجدول admin_permissions):
- GET/POST/PATCH/DELETE /admin/hr/employees
- GET/POST /admin/hr/attendance (تسجيل حضور يومي)
- GET/POST/PATCH /admin/hr/leave-requests (تقديم واعتماد الإجازات)
- GET/POST /admin/hr/payroll (كشف رواتب شهري، حساب صافي الراتب تلقائيًا: base_salary + bonuses - deductions)

واجهة: أضف قسم "شؤون الموظفين" بالقائمة الجانبية بأيقونة مناسبة، بأربع تبويبات فرعية (الموظفين، الحضور والانصراف، الإجازات، الرواتب).

## 2. المحاسبة والتقارير المالية

جداول جديدة:
- expenses: id, category (enum: rent, salaries, utilities, marketing, shipping, other), amount, description, expense_date, receipt_url (اختياري), created_by (FK)
- financial_periods: id, period_start, period_end, total_revenue, total_expenses, net_profit, status (enum: draft, closed)

Endpoints (صلاحية "finance":"view"/"edit"/"delete"):
- GET/POST/PATCH/DELETE /admin/finance/expenses
- GET /admin/finance/reports/summary?from=DATE&to=DATE — يرجع: إجمالي المبيعات (من storefront_orders حيث payment_status=paid)، إجمالي المصروفات، صافي الربح، عدد الطلبات، متوسط قيمة الطلب — لنطاق تاريخي محدد
- GET /admin/finance/reports/monthly — تقرير شهري تلقائي (12 شهر سابقة) بنفس المقاييس فوق لكل شهر، لعرض رسم بياني

واجهة: أضف قسم "المالية" بالقائمة الجانبية، بتبويبات (نظرة عامة/رسم بياني، المصروفات، التقارير الشهرية).

## 3. التصنيع والمعارض

جداول جديدة:
- manufacturing_batches: id, product_id (FK إلى storefront_products), batch_number (unique), quantity_produced, production_date, expiry_date, cost_per_unit, status (enum: in_production, completed, quality_check, approved, rejected)
- exhibitions: id, name_ar, name_en, location, start_date, end_date, budget, status (enum: planned, ongoing, completed, cancelled), notes
- exhibition_products: id, exhibition_id (FK), product_id (FK), quantity_allocated, quantity_sold

Endpoints (صلاحية "manufacturing":"view"/"edit"/"delete" لدفعات التصنيع، و"exhibitions":"view"/"edit"/"delete" للمعارض — أضف كلا الصلاحيتين):
- GET/POST/PATCH/DELETE /admin/manufacturing/batches
- GET/POST/PATCH/DELETE /admin/exhibitions
- GET/POST /admin/exhibitions/:id/products (ربط منتجات بمعرض معين وتتبع الكمية المخصصة والمباعة)

واجهة: أضف قسمين منفصلين بالقائمة الجانبية: "التصنيع" و"المعارض".

## ملاحظات عامة إلزامية لكل الوحدات الثلاث

1. أضف كل الصلاحيات الجديدة (hr, finance, manufacturing, exhibitions × view/edit/delete = 12 صلاحية جديدة) لجدول admin_permissions عبر seed، وتأكد إن Super Admin يحصل عليها تلقائيًا (نفس المنطق الحالي).
2. طبّق كل قيود enum بصرامة (رفض أي قيمة غير موجودة ضمن enum المحدد).
3. لا تلمس أي جدول أو route خاص بمتجر العملاء (storefront_*) إلا بعلاقة قراءة فقط (foreign keys للربط، مثل product_id).
4. طبّق الـ schema (pnpm --filter @workspace/db run push).
5. اكتب اختبارات لكل وحدة تتحقق من: نجاح العمليات الأساسية، رفض enum غير صحيح، رفض الوصول بدون الصلاحية المطلوبة (403).
6. شغّل pnpm run typecheck وتأكد من نجاحه.

اعطني ملخص شامل ودقيق: الملفات الجديدة/المعدّلة، الجداول المُنشأة فعليًا، عدد الاختبارات ونتيجتها، وأي فجوة أو نقص لم تتمكن من إكماله — لا تُجمّل التقرير، أذكر أي مشكلة فعلية واجهتك بصراحة.
