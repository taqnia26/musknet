أصلح 4 مشاكل بواجهة لوحة تحكم مسك اللولو (ولاحظ أن المشكلة الرابعة تخص الموقع كامل، مو بس لوحة التحكم):

## 1. خط القائمة الجانبية (Sidebar) خشن جدًا
النصوص العربية بالقائمة الجانبية (لوحة القيادة، المنتجات، الأقسام، الطلبات، الكوبونات، العملاء، المخزون، الموزعين، فريق العمل) تستخدم حاليًا خط ثقيل/فج غير مناسب. استبدله بخط **Tajawal** (خط العلامة التجارية الرسمي للعربي حسب دليل الهوية)، بوزن Regular للعناصر العادية وBold للعنصر النشط (active) فقط. تأكد أن Tajawal مستورد فعليًا (Google Fonts) ومطبّق على كل النصوص العربية بلوحة التحكم، مو بس القائمة الجانبية.

## 2. ترجمة تسميات الصلاحيات (Permissions) للعربي
حاليًا بشاشة "إضافة/تعديل مستخدم" تحت "الصلاحيات"، الأسماء تظهر بالإنجليزي (مثل "categories - view"، "dashboard - edit"، "products - delete") رغم أن الواجهة بالكامل عربية. 

المطلوب: أضف طبقة ترجمة عرضية فقط (Display mapping) بدون تغيير القيم الفعلية المخزنة بقاعدة البيانات أو المرسلة للـ API (module و action لازم يبقوا بالإنجليزي بالباك-إند كما هم: products, categories, orders, coupons, customers, inventory, distributors, staff, dashboard / view, edit, delete).

مثال الترجمة المطلوبة للعرض فقط:
- dashboard → لوحة القيادة
- products → المنتجات
- categories → الأقسام
- orders → الطلبات
- coupons → الكوبونات
- customers → العملاء
- inventory → المخزون
- distributors → الموزعين
- staff → فريق العمل
- view → مشاهدة
- edit → تعديل
- delete → حذف

اعرض التسمية بصيغة "المنتجات - مشاهدة" بدل "products - view".

## 3. تأكيد فعلي: هل الموقع مربوط بباك-إند حقيقي أم عرض واجهة فقط؟
أعطني تقرير دقيق وصريح: 
- هل كل قسم بلوحة التحكم (لوحة القيادة، المنتجات، الأقسام، الطلبات، الكوبونات، العملاء، المخزون، الموزعين، فريق العمل) يقرأ ويكتب فعليًا من قاعدة بيانات PostgreSQL عبر استدعاءات API حقيقية، أم أن أي قسم منها لسا يعرض بيانات وهمية/ثابتة (mock/static data) بالواجهة فقط بدون اتصال فعلي بالخادم؟
- اذكر لي تحديدًا أي قسم إن وُجد لسا غير مربوط فعليًا، حتى لو كان جزءًا بسيطًا منه.
- لا تفترض أو تُجمّل الإجابة — افحص الكود فعليًا وأعطني حالة كل قسم بصراحة.

## 4. إصلاح تصميم مفتاح التبديل (Toggle Switch) في كل الموقع
مكوّن التبديل (Switch/Toggle) الحالي شكله سليم بالحالة المطفأة (رمادي، مثل "مدير عام" بحالتها الحالية)، لكن عند التفعيل (الحالة النشطة/checked) يظهر بتصميم مكسور أو غير متناسق (تباين لوني غير مريح أو حدود غريبة).

المطلوب: أصلح ستايل الحالة النشطة (checked state) لمكوّن التبديل بحيث يستخدم أحد ألوان الهوية البصرية الرسمية (Peach Gold #FDC87F أو Terracotta #C47B47) كخلفية بحالة التفعيل، مع دائرة التبديل (thumb) بلون أبيض أو Charcoal Grey حسب التباين الأنسب. طبّق هذا الإصلاح على **كل مكان بالموقع** يستخدم هذا المكوّن (لوحة التحكم بالكامل + أي مكان بواجهة المتجر العامة storefront لو موجود فيها toggle مشابه)، مو بس مكان واحد.

بعد التطبيق، اعطني ملخص دقيق بالملفات المعدّلة، وأجب بوضوح على سؤال النقطة 3 دون تجميل.
